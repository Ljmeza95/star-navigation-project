Using Acceltest

1. install and open Arduino IDE at https://www.arduino.cc/en/software/?_gl=1*cbq9cg*_up*MQ..*_ga*MTE2MzQxMDMwOS4xNzQ2NTY4Nzk1*_ga_NEXN8H46L5*czE3NDY1Njg3OTQkbzEkZzAkdDE3NDY1Njg3OTQkajAkbDAkaDE1Mzg5NDg0NDI.#ide

2. install the following and their dependencies from the library manager
   -Adafruit LSM303 Accel
   -Adafruit LIS2MDL
3. If dependencies not installed, install Adafruit_LSM303DLH_Mag, Adafruit BusIO, and Adafruit Unified Sensor

4. plug in arduino, select board in top left dropdown, and run

5. If it says "access not granted," unplug arduino and repeat 4
